GEO / AEO platform that tracks how ChatGPT, Gemini, Perplexity, Google AI Overviews and Bing Copilot answer buyers' questions: who gets mentioned, which sources get cited, and what to fix next.
- Multi-provider LLM monitoring pipeline with brand-mention extraction, competitor share-of-voice and citation analysis

- Search Console / Bing Webmaster integrations and AI-crawler & referral traffic tracking

**AI-enhanced GEM strategy optimization** — quantitative investing research using XGBoost and other models to improve a Global Equity Momentum strategy.
